# ⚙️ TinyPredict AI: Edge-Optimized Predictive Maintenance & Repair System

TinyPredict AI is a lightweight Edge-AI framework designed for industrial predictive maintenance and automated repair guidance. It detects machinery anomalies using real-time sensor data and provides step-by-step repair advisory via RAG integration.

## 🌟 Key Features
- **Edge Anomaly Detection:** Lightweight Isolation Forest ML model running on local edge devices (Raspberry Pi / Jetson).
- **Real-Time Telemetry:** Live tracking of vibration levels and temperature parameters.
- **RAG Repair Advisor:** Automated diagnostic insights and ISO-standard maintenance recommendations.
- **Low Cost & High Scalability:** Zero dependence on expensive cloud infrastructure.

## 🛠️ Tech Stack
- **Language:** Python
- **Machine Learning:** Scikit-Learn, NumPy, Pandas
- **Dashboard:** Streamlit
- **Architecture:** Edge AI, Agentic RAG Framework
